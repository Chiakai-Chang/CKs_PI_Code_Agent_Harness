# 憲法 —— PiTaskLab

這個專案的存在目的:**作為 C.A.S.E. 任務執行的乾淨場地。**

任務在這裡被執行,是為了回答一個問題:**一份寫得好的任務包,能不能被完整執行完?**
先前的實驗全部在暫存目錄裡進行,而那些目錄的名字本身就會誤導執行者
(2026-08-11 查證:探針 cwd 含有 harness 名稱,造成四次「跑錯專案」)。
這裡沒有那個問題。

## 不可違反的規則

1. **不得自我核可。** 任務走到 `REVIEW` 之後,由人類驗收,不由執行者自己宣布完成。
2. **交付前必須逐條對照該任務的 Local DoD**,並附上實際跑過的指令與輸出。
   驗證不了的部分要明講,不得以「應該可以」帶過。
3. **只在這個專案目錄內工作。** 不修改此目錄之外的任何檔案。
4. **一次一個任務。** 目前 `IN_PROGRESS` 的任務完成或轉出之前,不認領下一個。
5. **沒有產出就不算完成。** Local DoD 點名的檔案不存在時,不得進入 `REVIEW`。

## 狀態

`PENDING` → `IN_PROGRESS` → `REVIEW` → `DONE`,不得跳步。
卡住時走 `ESCALATED`,並在任務資料夾裡寫明卡在哪。
