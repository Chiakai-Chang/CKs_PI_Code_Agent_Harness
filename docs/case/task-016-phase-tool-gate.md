階段由 C.A.S.E. 協定狀態推導,在 `tool_call` 擋 —— 形狀取自 `research/auto-pi`
(`loop.ts:1020` 的 phase tool allowlist),階段模型**不**取自它(它的階段來自自己的
workflow,會與協定打架)。

* **PLAN**(已認領、`planning.md` 無 `## Self-Review`):擋任務包內的交付物寫入;
  **研究工具全開** —— 擁有者說得很清楚:「他多搜幾次是好的阿?越多越好不是?」
* 其餘 / 讀不到 / 多個 open task:完全不擋。

四次擋阻,每次理由不同(取自 OmniHeal 3-Strike 的「換一種方式」層),第五次放行。
