### 倒退的原因:守衛不檢查狀態值是否合法

run 2 的序列:

```
INJECT: 把 status.txt 改成 IN_PROGRESS
WRITE status.txt <- 'IN_PROGRESS'     ← 認領成功
WRITE status.txt <- 'COMPLETE'        ← 不是合法狀態,放行
INJECT: 請認領                          ← 推進器看不懂,退回起點
WRITE status.txt <- ''                ← 空字串,也放行
INJECT ×2                              ← 同一句話重複
```

`task-queue-guard.ts:261`:

```ts
if (!VALID_STATUSES.includes(next)) return null;   // the verifier's business
```

**守衛檢查合法狀態「之間」的轉換,不檢查「這是不是合法狀態」。**
非法值被明確放行,理由是那屬於 verifier —— **而這個迴圈裡沒有 verifier。**

一次非法寫入就讓狀態機停擺:之後每一次 `nextStep()` 都讀到看不懂的狀態、
都退回「請認領」,而模型已經認為自己做完了。

**這是一條被寫下來的刻意決定,在這個情境下是錯的** ——
本 repo 的疤:未寫下的否決會被重做,而寫下的否決也可能過期。
